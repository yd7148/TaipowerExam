### 第5題

**【官方答案：(D)】**

有一台電動機接於 100sqrt(2)sin(1000t) 之電源，產生 P = 4 kW，QL = 8 kvar。若希望將其 PF 提高至0.8，則需要並聯多少法拉(F)之電容器？

(A) 50 uF (B) 100 uF (C) 250 uF (D) 500 uF

**【解題】**

- 電源有效值 V = 100 V，omega = 1000 rad/s
- 原功率因數：S = sqrt(P^2 + QL^2) = sqrt(4000^2 + 8000^2) = 4000sqrt(5) VA
- 原 PF = P/S = 4000/(4000sqrt(5)) = 1/sqrt(5)，Q 原 = 8000 var（感性）
- 目標 PF = 0.8，則 theta2 = cos^-1(0.8)，tan(theta2) = 0.75
- Q2 = P x tan(theta2) = 4000 x 0.75 = 3000 var
- 需要補償的無功功率：DeltaQ = 8000 - 3000 = 5000 var
- DeltaQ = V^2 x omega x C -> C = DeltaQ / (V^2 x omega) = 5000 / (100^2 x 1000) = **500 uF**
