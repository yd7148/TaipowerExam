### 第1題（1.5分）
**題目**：下列有關理想的R、L、C三元件串聯電路之敘述，何者有誤？

(A) 發生諧振現象時，電路的阻抗值最小
(B) 發生諧振現象之頻率與電阻R無關
(C) 電阻R越大，品質因數越高
(D) 不一定為低通濾波器

**官方答案**：**(C)**

**詳解**：
- (A) 正確：RLC串聯諧振時，感抗與容抗互相抵消（jωL = 1/jωC），阻抗Z = R，為最小值。
- (B) 正確：諧振頻率 ω₀ = 1/√(LC)，與R無關。
- (C) **錯誤**：品質因數 Q = ω₀L/R = 1/(ω₀CR)，R越大，Q值越**低**，而非越高。
- (D) 正確：RLC串聯電路根據輸出取自哪個元件，可為低通、高通或帶通濾波器。

### 第2題（1.5分）
**題目**：下列有關對稱函數的傅立葉級數展開之敘述，何者有誤？

(A) 偶對稱函數不存在正弦波成分
(B) 四分之一波對稱函數僅存在偶次諧波成分
(C) 奇對稱函數不存在餘弦波成分
(D) 半波對稱函數僅存在奇次諧波成分

**官方答案**：**(B)**

**詳解**：
- (A) 正確：偶對稱函數 f(t) = f(-t)，其傅立葉級數只含餘弦項（含直流項），不含正弦項。
- (B) **錯誤**：四分之一波對稱函數（quarter-wave symmetry）僅存在**奇次諧波**成分，且根據是偶或奇對稱再分為僅含奇次諧波的奇數倍正弦或餘弦。並非偶次諧波。
- (C) 正確：奇對稱函數 f(t) = -f(-t)，其傅立葉級數只含正弦項，不含餘弦項。
- (D) 正確：半波對稱函數 f(t) = -f(t ± T/2)，僅存在奇次諧波。

### 第3題（1.5分）
**題目**：請求出電壓 v(t) = 10cos(10t+30°) 的振盪週期T，及與電流 i(t) = -5sin(10t-70°) 間的相位關係為何？

(A) π/5，電壓領先電流10°
(B) π/5，電流領先電壓10°
(C) π/10，電壓領先電流100°
(D) π/10，電流領先電壓100°

**官方答案**：**(A)**

**詳解**：
- 角頻率 ω = 10 rad/s
- 週期 T = 2π/ω = 2π/10 = **π/5** 秒

電流轉換為餘弦形式：
- i(t) = -5sin(10t-70°) = 5cos(10t-70°+90°) = 5cos(10t+20°)

相位比較：
- 電壓相位：30°
- 電流相位：20°
- 電壓領先電流 = 30° - 20° = **10°**

### 第4題（1.5分）
**題目**：下列有關平衡三相系統之敘述，何者正確？

(A) Δ型接法，相電壓是線電壓的√3倍
(B) Δ型接法，相電流是線電流的√3倍
(C) Y型接法，相電壓與線電壓相等
(D) Y型接法，相電流與線電流相等

**官方答案**：**(D)**

**詳解**：
- Δ型接法：V_L = V_P（線電壓等於相電壓），I_L = √3 I_P（線電流是相電流的√3倍）
- Y型接法：V_L = √3 V_P（線電壓是相電壓的√3倍），**I_L = I_P（線電流等於相電流）**

因此 (A)(B)(C) 均錯誤，(D) 正確。

**題目**：有一正相序平衡三相電壓源，線電壓 Vab = 50√3∠30° V，經由每相線路阻抗為 1+j0.5 Ω 的傳輸線，傳送電力到單相阻抗值為 9+j7.5 Ω 的平衡Δ接負載，請問a相的線電流 Ia 為何？

(B) 10∠-36.87° A

### 第7題（1.5分）
**題目**：求 F(s) = (s+1)/(s²+7s+12) 的逆拉普拉斯轉換為何？

(A) -3e^(-3t) + 2e^(-4t)
(B) -2e^(-3t) + 3e^(-4t)
(C) 2e^(-3t) - 3e^(-4t)
(D) 3e^(-3t) - 2e^(-4t)

**官方答案**：**(B)**

**詳解**：
- 分母因式分解：s²+7s+12 = (s+3)(s+4)
- 部分分式展開：F(s) = (s+1)/[(s+3)(s+4)] = A/(s+3) + B/(s+4)

求A：A = (s+1)/(s+4)|_{s=-3} = (-2)/(1) = -2
求B：B = (s+1)/(s+3)|_{s=-4} = (-3)/(-1) = 3

- F(s) = -2/(s+3) + 3/(s+4)
- f(t) = **-2e^(-3t) + 3e^(-4t)**

**題目**：有一個RL串聯低通濾波器的截止頻率為4 kHz，假設電阻R=10 kΩ，求電感L及24 kHz時的 |H(jω)| 為何？

轉移函數：H(jω) = R/(R+jωL)

- |H(jω)| = R/√(R² + (ωL)²)
- ωL = 150796 × 0.40 = 60318.6 Ω
- |H(jω)| = 10000/√(10000² + 60318.6²) = 10000/61144.7 ≈ **0.164**

### 第20題（1.5分）
**題目**：有一放大器電路其轉移函數為 s/(s²+7s+12)，此為何種濾波器？

(A) 帶通濾波器　(B) 帶拒濾波器　(C) 低通濾波器　(D) 高通濾波器

**官方答案**：**(A)**

**詳解**：
- 轉移函數 H(s) = s/(s²+7s+12) = s/[(s+3)(s+4)]

分析頻率響應：
- 當 s = jω → H(jω) = jω/[(jω+3)(jω+4)]
- ω → 0：|H| → 0（低頻被衰減）
- ω → ∞：|H| → ω/ω² → 0（高頻被衰減）
- 中間頻率有最大增益

低頻和高頻都被衰減，中間頻率通過 → **帶通濾波器**

### 第21題（1.5分）
**題目**：下列關於負回授電路之敘述，何者有誤？

(A) 電壓取樣、電流回授可降低輸入阻抗
(B) 迴路增益(Loop Gain)在相位移180°下，增益小於1，電路才會穩定
(C) 對於單一極點之開迴路放大器，加入電阻性負載後，電路一定穩定
(D) 電流取樣、電壓回授可降低輸出阻抗

**官方答案**：**(D)**

**詳解**：

- (B) 正確：這是奈穩定準則（Nyquist criterion），環路增益在180°相移時小於1才穩定。
