## 第 1 題 【電路學】

**題目：** 電流 i(t) = [5cos(ωt+36.87°) + 10cos(ωt-53.13°)] A，如改用相量表示為何？
**選項：** (A) 11.2∠-26.6° A  (B) 11.2∠-53.2° A  (C) 22.4∠-26.6° A  (D) 22.4∠-53.2° A
**官方答案：** (A)

### 詳解

**步驟一：將各分量轉為相量形式**

- 第一分量：5∠36.87° A = 5(cos36.87° + j sin36.87°) = 5(0.8 + j0.6) = 4 + j3 A
- 第二分量：10∠-53.13° A = 10(cos(-53.13°) + j sin(-53.13°)) = 10(0.6 - j0.8) = 6 - j8 A

**步驟二：相加**

I = (4 + j3) + (6 - j8) = 10 - j5 A

**步驟三：轉為極坐標**

- |I| = √(10² + 5²) = √125 = 11.18 ≈ 11.2 A
- θ = tan⁻¹(-5/10) = tan⁻¹(-0.5) = -26.57° ≈ -26.6°

**答案：(A) 11.2∠-26.6° A**

## 第 3 題 【電路學】

**題目：** 有一電壓源 V(t) = 100 + 20cos(3t-20°) + 10cos(5t+10°) + 10cos(7t-30°) V 串聯 1Ω 電阻，則 1Ω 電阻所吸收之平均功率為何？
**選項：** (A) 5300 W  (B) 8050 W  (C) 10300 W  (D) 10525 W
**官方答案：** (C)

### 詳解

**步驟一：各分量功率獨立計算（直流 + 各諧波）**

- 直流分量（100 V）：P₀ = V²/R = 100²/1 = 10000 W
- 3t 分量（20Vpeak）：P₁ = V²/(2R) = 20²/2 = 200 W
- 5t 分量（10Vpeak）：P₂ = 10²/2 = 50 W
- 7t 分量（10Vpeak）：P₃ = 10²/2 = 50 W

**步驟二：加總**

P_total = 10000 + 200 + 50 + 50 = 10300 W

**答案：(C) 10300 W**

## 第 4 題 【電路學】

**題目：** 有一 RLC 並聯電路，其自然響應 V(t) = Ae^(-αt)sin ωt，A 為常數，α > 0，ω > 0。有關 V(t) 敘述，下列何者有誤？
**選項：** (A) 電壓會在正值、負值間交替  (B) 電壓振盪的幅度呈指數衰減  (C) α值會影響電壓衰減的速度  (D) 此為臨界阻尼響應
**官方答案：** (D)

### 詳解

**分析：**

V(t) = Ae^(-αt)sin ωt 的特性：

- sin ωt → 電壓在正負值間交替 ✓ (A正確)
- e^(-αt) → 振盪幅度呈指數衰減 ✓ (B正確)
- α 控制衰減速度 ✓ (C正確)
- 此形式為「欠阻尼」（underdamped）響應，非臨界阻尼 ✗ (D錯誤)

臨界阻尼的形式為 V(t) = (A + Bt)e^(-αt)，不含 sin 項。

**答案：(D) 此為臨界阻尼響應（此敘述有誤）**

## 第 6 題 【電路學】

**題目：** 有一電容器 C = 0.5 F，其電流 i(t) = 6t A。已知 t = 0 s 時，電容器上之電壓為 2 V，求 t = 1 s 時，儲存於電容器之能量為何？
**選項：** (A) 8 J  (B) 16 J  (C) 24 J  (D) 32 J
**官方答案：** (B)

### 詳解

**步驟一：求電壓**

v(t) = v(0) + (1/C)∫₀ᵗ i(τ)dτ
     = 2 + (1/0.5)∫₀ᵗ 6τ dτ
     = 2 + 2 × 3τ²|₀ᵗ
     = 2 + 6t²

**步驟二：t=1s 時的電壓**

v(1) = 2 + 6(1)² = 8 V

**步驟三：計算能量**

W = ½CV² = ½ × 0.5 × 8² = ½ × 0.5 × 64 = 16 J

**答案：(B) 16 J**

## 第 12 題 【電路學】

**題目：** 有一 RLC 串聯電路，連接一個 60 Hz，100 V 之電源。電路之 R = 10Ω，X_L = 50Ω，X_C = -0.5Ω，則此電路之諧振頻率為何？
**選項：** (A) 6 Hz  (B) 12 Hz  (C) 18 Hz  (D) 24 Hz
**官方答案：** (A)

### 詳解

**步驟一：求諧振頻率與工作頻率的關係**

諧振條件：X_L(f₀) = |X_C(f₀)|
2πf₀L = 1/(2πf₀C)

已知在 f = 60Hz 時：X_L = 50Ω，|X_C| = 0.5Ω

**步驟二：利用比例關係**

f₀²/f² = |X_C|/X_L = 0.5/50 = 0.01

f₀ = 60 × √0.01 = 60 × 0.1 = 6 Hz

**答案：(A) 6 Hz**

## 第 13 題 【電路學】

**題目：** 有兩條有兩條銅線，銅線 A 的直徑及長度皆為銅線 B 的 2 倍。若在兩條銅線加上相同電壓，則銅線 A 所消耗功率為銅線 B 的幾倍？
**選項：** (A) 1/4  (B) 1/2  (C) 2  (D) 4
**官方答案：** (C)

### 詳解

**步驟一：電阻公式**

R = ρL/A，A 為截面積 = π(d/2)²

**步驟二：比較電阻**

- R_A = ρ(2L_B) / (π(d_A/2)²) = ρ(2L_B) / (π(d_B)²)
- R_B = ρL_B / (π(d_B/2)²) = ρL_B / (πd_B²/4)

R_A/R_B = [2L_B/(πd_B²)] / [4L_B/(πd_B²)] = 2/4 = 1/2

**步驟三：比較功率（同電壓）**

P = V²/R
P_A/P_B = R_B/R_A = 2

**答案：(C) 2 倍**

## 第 15 題 【電路學】

**題目：** 有一電感 L = 100 mH，當 t < 0，其兩端電壓為 0 V。當 t ≥ 0，其兩端電壓 V(t) = 20te^(-10t) V。假設 t ≤ 0 時，i_L = 0 A。求 t = 0.2 s 時，i_L 值 =？
**選項：** (A) 1.05 A  (B) 1.19 A  (C) 2.11 A  (D) 2.37 A
**官方答案：** (B)

### 詳解

**步驟一：利用 i_L = (1/L)∫₀ᵗ V(τ)dτ**

i_L = (1/0.1)∫₀ᵗ 20τe^(-10τ) dτ = 200∫₀ᵗ τe^(-10τ) dτ

**步驟二：分部積分**

∫τe^(-10τ) dτ = -τe^(-10τ)/10 - e^(-10τ)/100

代入上下限 0 到 t：
= [-te^(-10t)/10 - e^(-10t)/100] - [0 - 1/100]
= -te^(-10t)/10 - e^(-10t)/100 + 1/100

**步驟三：代入 t = 0.2**

i_L(0.2) = 200 × [-0.2×e⁻²/10 - e⁻²/100 + 1/100]
= 200 × [-0.2×0.1353/10 - 0.1353/100 + 0.01]
= 200 × [-0.002706 - 0.001353 + 0.01]
= 200 × 0.005941
= 1.188 A ≈ 1.19 A

**答案：(B) 1.19 A**

**題目：** 有一 RLC 串聯電路，R = 560Ω，L = 100 mH，C = 0.1μF，其電流之自然響應特性為何？
**選項：** (A) 過阻尼  (B) 欠阻尼  (C) 臨界阻尼  (D) 無阻尼

## 第 17 題 【電路學】

**題目：** 如右圖之電路，t = 0 s 時，S1 閉合，t = 5 s 時，S2 閉合。當 0 ≤ t ≤ 5 時，求電路之 i(t) =？（40V、4Ω、2Ω、10V、6Ω、5H）
